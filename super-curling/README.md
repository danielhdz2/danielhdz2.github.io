# Super Curling 16-bit (PWA)

Juego de curling 2D con estética de consola de 16 bits. Instalable y jugable sin conexión.

## Publicar en GitHub Pages
1. Sube todo el contenido de esta carpeta a la raíz de un repositorio público.
2. Settings → Pages → Deploy from a branch → rama `main`, carpeta `/ (root)`.
3. Abre `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

Para probar en local (HTTPS o localhost): `python3 -m http.server 8000` y abre http://localhost:8000
Si cambias algún archivo, sube el número de `CACHE_NAME` en `service-worker.js` para que se actualice.
